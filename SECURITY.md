# Security

Report a vulnerability in this project in either place:

- [GitHub issues](https://github.com/QuazarMedia/simt-dev/issues)
- [security@simt.space](mailto:security@simt.space)

Say which version you ran, the command, and what you observed. Leave out tokens,
credentials, and the contents of a repository that is not this one.

An issue is visible to everyone who can see this repository. Use the email when
the report itself should stay private.
