# Security

Supported versions: the latest `0.x` release. An older release is fixed only when the
report describes a defect this checkout reproduces and the fix does not require
rewriting the recorded format.

Report privately first, to [security@simt.space](mailto:security@simt.space). Use this
channel when the report itself should stay private — a public issue is visible to
everyone who can see this repository, and a fix that lands before the report is public
is worth more than one that lands after.

- [security@simt.space](mailto:security@simt.space) — private, preferred
- [GitHub issues](https://github.com/QuazarMedia/simt-dev/issues) — public, for anything
  already disclosed or for a question rather than a vulnerability

Say which version you ran, the command, and what you observed. Leave out tokens,
credentials, and the contents of a repository that is not this one.
