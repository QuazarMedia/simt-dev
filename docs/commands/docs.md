# simt docs

Rendered from the command spec by `simt docs commands --yes`; do not edit by hand.

| Command | Flags | What it does |
| --- | --- | --- |
| `simt docs commands` | `--yes`, `--diff`, `--dry-run` | render the command reference in docs/commands from the spec |

Writes to the repository: `simt docs commands`. Each prints its plan and writes nothing without `--yes`.
