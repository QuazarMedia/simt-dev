# Module and MCP reference

| Module | CLI commands | Read-only MCP tools | When an agent should use it |
| --- | --- | --- | --- |
| **Task Brief** | `simt brief "<task>" [--budget <n>] [--explain]`, `simt work packet --input <file>` | `brief`, `work_packet` | First call on every task to get task kind, commands, ranked files, tests, ADRs, skills, and lessons in <= 2 KB; `work packet` when the packet must prove its units are cited |
| **Code Graph & Retrieval** | `simt index [--open] [--search <task>] [--rank <task>]`, `simt index overlay --input <file>`, `simt map`, `simt impact`, `simt tests`, `simt gate` | `federation_query`, `index_overlay` | Before editing to rank files (`map`), trace blast radius (`impact`), run only diff-affected tests (`gate --changed`), or ask the open cache (`index --search`) |
| **Knowledge & Governance** | `simt why [path]`, `simt rules list`, `simt rules show <id>`, `simt rules why <id>`, `simt decide`, `simt knowledge why, rank, impact, derivations, debt, sections`, `simt knowledge export, import` | `rules_list`, `rules_why`, `knowledge_why`, `knowledge_export`, `knowledge_import` | Before touching governed files (`why`), when ranking evidence or asking what a change puts in question, or when moving claims between repositories as data |
| **Verification** | `simt verify plan`, `simt verify select`, `simt verify status`, `simt verify contracts, documents, procedures --input <file>` | `verify_plan`, `verify_select`, `verify_status`, `verify_contracts`, `verify_documents`, `verify_procedures` | Before choosing checks, when closing recorded obligations, or when checking a generated document, a procedure or a set of obligation results |
| **Actions & Adapters** | `simt action status --input <file>`, `simt action review --input <file>`, `simt adapter check --input <file>` | `action_status`, `action_review`, `adapter_check` | Before executing an operation: read the journal state, review the bundle, and validate an adapter descriptor as data |
| **Skills & Disclosure** | `simt skills index`, `brief`, `show`, `why`, `find`, `install`, `compile`, `eval`, `simt graph lint` | `skills_index`, `skills_find`, `skills_brief`, `skills_show`, `skills_why` | When a task requires domain workflows or reference docs without blowing the session token budget |
| **Memory & Lessons** | `simt lessons list`, `simt lessons review <id> --yes`, `simt lessons discover --input <file>` | `lessons_discover` | After fixing a failing test/gate or hitting a hook denial, to inspect or promote reusable failure-to-fix lessons, or to deduplicate discovery candidates |
| **Work & Plans** | `simt work inspect`, `simt work schedule, handoff, resume, graduate --input <file>`, `simt plan status`, `simt plan next [<id>]`, `simt plan done <id> [<sha>] --yes`, `simt slice start`, `finish <id>`, `simt lease`, `simt pr-body`, `simt status --line`, `simt undo` | `work_inspect`, `plan_next`, `plan_done`, `pr_body` | When describing a repository's work, sequencing ready tasks, resuming a handoff, or executing a phased plan row by row |
| **Adoption & Projection** | `simt init`, `simt doctor`, `simt check`, `simt sync`, `simt upgrade` | `doctor`, `check` | When adopting a repo, diagnosing stack/config health, or verifying zero drift before commit |
| **Dual Gates & Evidence** | `simt hooks install`, `status`, `run`, `simt agent-hooks install`, `status`, `simt agent-hook`, `simt evidence [check]`, `simt evidence validate --input <file>` | `evidence_validate` | When installing git/agent hooks, running gates manually, or validating a test claim and its chain of custody before committing |
| **Context & Harnesses** | `simt tokens`, `simt harness detect`, `loaders`, `simt shared plan`, `install` | — | When auditing startup token cost across harnesses (`claude`, `codex`, `cursor`, `opencode`, `antigravity`, `copilot`, `deepseek`) or deduplicating workspace rules |
| **Workspace & Benchmarks** | `simt compare`, `simt bench mine`, `run`, `report`, `ablate`, `probes`, `replay`, `calibrate`, `compat`, `corpus`, `world`, `simt local doctor`, `simt review [--local]`, `simt distill` | `compare` | When auditing an entire multi-repo estate, measuring rule uplift/cost, replaying an outcome, calibrating autonomy, or probing local model endpoints |

The command names and their flags are generated in [../commands/index.md](../commands/index.md);
this table is the shape of the surface, not its contract.
